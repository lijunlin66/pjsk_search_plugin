# Game UI assets

PNG card frames, attribute icons and rarity marks are game UI artwork distributed by the Sekai Viewer asset collection:
https://github.com/Sekai-World/sekai-viewer/tree/dev/src/assets

They remain copyright of the respective Project SEKAI rights holders, including SEGA, Colorful Palette and Crypton. The plugin's MIT code license does not grant rights to these images.
No upstream program code is included. Skill badges and the geometric background are drawn locally by this plugin.

The root logo.png uses the maintainer-supplied Project SEKAI character image, resized without redrawing to 256×256 PNG. The original character artwork remains with its respective rights holders; it is not covered by the plugin code MIT license.
